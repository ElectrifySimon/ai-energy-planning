# AI in energy planning: closing the delivery gap

Long-read version of the IRENA Expert Insight published ahead of Energy Planning Week 2026 (Bonn, 1 to 4 December 2026), with the figures built as interactive charts.

By Simon Benmarraze, Nadeem Goussous and Juan Jose Garcia Mendez, IRENA.

## What is here

| Path | Purpose |
|---|---|
| `index.html` | The article. Generated by `build.py`, do not hand-edit. |
| `styles.css` | Page CSS. |
| `app.js` | The three ECharts figures. |
| `build.py` | Writes `index.html` from the article text and renumbers citations. |
| `vendor/echarts.min.js` | Apache ECharts 5.5.1, vendored so the page needs no CDN. |
| `fonts/` | Inter and Montserrat, latin subset, self-hosted. |

## Figures

1. **Data centre electricity demand in the EU**, 68 TWh in 2024 and a projected 114 TWh in 2030. Source: European Commission (2026).
2. **Who uses LEAP**, 65 of 210 countries and territories. Source: Stockholm Environment Institute (2026).
3. **Solver speed relative to HiGHS**, up to 16 times on the Open Energy Benchmark. Vendor-reported prototype benchmark, labelled as such on the page.

The other panels (five value clusters, SAGES commitments, 2026-2028 actions) carry no numbers beyond the source text.

## Build

```bash
python3 build.py
```

Citations in the source text are written with the Word document's numbering. `build.py` maps them to sequential order by first appearance and drops unused entries, so the reference list always matches the body. An undefined citation fails the build.

## Deploy

Static files served from the repository root by GitHub Pages. No build step runs on the server.
